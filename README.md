# Memory Palace · 记忆宫殿

一个 Minecraft Java 版（Fabric）模组：把 Markdown / LaTeX 笔记放进世界里的书架上，搭建属于自己的记忆宫殿。

笔记以普通 `.md` 文件保存在存档旁边，世界里的"笔记书"只记录一个 ID——书架被苦力怕炸掉，笔记也不会丢失；在 Obsidian 等外部编辑器中修改，游戏里即时刷新。

## 功能

- **笔记书与书架**：笔记书即原版成书，可放入原版雕纹书架（每架 6 本）或讲台。右键阅读，潜行 + 右键取出。卸载模组后，书仍是普通成书，书页上写有对应的笔记文件名。
- **原版书本风格阅读界面**：左右两页摊开的原版书，书页大小与字体大小可分别调整（书页变大时字号不变、每页行数增多）。
- **Markdown 与 LaTeX**：标题、列表、任务清单、引用、代码块、表格、链接；行内公式 `$...$` 与行间公式 `$$...$$` 渲染为图片；支持本地图片（`![说明](图.png)` 与 Obsidian 的 `![[图.png]]`）。
- **游戏内编辑器**：左页编辑、右页实时预览；`Ctrl+S` 保存；外部修改会提示冲突。
- **加密笔记（密码模式）**：Argon2id + AES-256-GCM；密码不保存；解密仅在客户端进行；可选恢复密钥；闲置自动上锁。
- **快速收集**：按 `K` 记下一个想法，自动写入当天的 `收件箱/yyyy-MM-dd.md`（写下第一条时才创建文件）。
- **找笔记与导航**：按 `J` 搜索标题、文件夹与正文，选中后以光柱与方向箭头（含上下高度差）引导至书架。
- **准星显示书名**：对准书架上的某一格时显示书名。
- **自动备份**：每次进入世界，将笔记库备份至存档之外（`.minecraft/memory-palace-backups/`）。

## 安装

需要：

- Minecraft Java 版 **26.3**
- [Fabric Loader](https://fabricmc.net/use/installer/) 0.20.1 或更高
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java 25（官方启动器自带）
- 可选：[Mod Menu](https://modrinth.com/mod/modmenu)（在模组列表中打开设置）

从 [Releases](../../releases) 下载 `memorypalace-x.y.z.jar`，与 Fabric API 一同放入 `.minecraft/mods/` 文件夹。

## 使用

| 操作 | 说明 |
|---|---|
| `/palace give <笔记或文件夹>` | 领取自己能读的笔记书（管理员可领任意笔记；文件夹单次最多 36 本） |
| `/palace new <路径>` | 新建笔记并在游戏内编辑（普通玩家建在个人区） |
| `/palace share <玩家\|everyone> read\|edit <笔记>` | 分享自己的笔记：只读 / 可编辑 |
| `/palace unshare <玩家\|everyone> <笔记>` | 取消分享；`everyone` 可将公开笔记改为私有 |
| `/palace newsecret <路径>` | 新建加密笔记（仅本机房主） |
| `/palace encrypt <笔记>` / `/palace decrypt <笔记>` | 加密 / 解除加密（仅本机房主；解除时会打开笔记，点书下方的「解密」，再输入密码并确认） |
| `/palace lock` | 立即上锁加密笔记（仅本机房主） |
| `/palace where <笔记>` | 查看自己能读的笔记所在的书架与讲台 |
| `/palace list [文件夹]` | 列出自己能读的笔记 |
| `/palace rescan` | 重新扫描笔记库（管理员） |
| `/palace visibility [everyone\|private]` | 查看 / 修改当前世界的笔记可见性，覆盖配置默认值（管理员） |
| `/palace reload` | 重新读取服务端配置（管理员） |
| `M` / `K` / `J` | 打开笔记窗口 / 快速收集 / 找笔记 |

按键均可在"选项 → 控制 → 按键绑定 → 记忆宫殿"中修改；进入世界时会提示与其他按键的冲突。

笔记库位于 `saves/<世界>/memory-palace/`，可直接用 Obsidian 打开。

**多人游戏（局域网、服务器）**：默认关闭。开启后，整个世界共用一个笔记库，权限按篇计算。

配置文件为 `config/memorypalace-server.toml`，首次启动世界或服务器时自动生成，内有注释。修改后，管理员可用 `/palace reload` 重新读取；专用服务器关闭多人时无人能用这条命令，需修改配置后重启。配置文件写坏、读取失败时，一律按默认设置（多人关闭）处理。

- `multiplayer`：默认 `false`，只有本机房主能用笔记，其他玩家看不到任何笔记；单人游戏不受影响。专用服务器没有本机房主，关闭时所有人都不能用。改为 `true` 才允许其他玩家按权限使用。
- `default_visibility`：默认 `"private"`（私有），也可设为 `"everyone"`（所有人可读），决定没写 `palace-read` 的笔记谁能读。世界用 `/palace visibility` 设置过后，以世界设置为准。
- `max_notes_per_player`：每个玩家最多创建的笔记数，默认 `200`；`0` 表示不限，管理员不受此限制。
- `max_note_chars`：游戏内保存时单篇笔记的字数上限，默认 `200000`；`0` 表示不限，管理员不受此限制。

权限通过 **fabric-permissions-api** 判断（已打包，无需另装）：`memorypalace.admin` 默认给本机房主或 2 级及以上 OP；`memorypalace.create`（新建）、`memorypalace.give`（领书）、`memorypalace.share`（分享及取消分享）默认所有人都有。装了 LuckPerms 后，服主可按组授予或收回这些权限；管理员始终拥有新建、领书和分享权限，但仍受多人开关和单篇笔记权限约束。

- **新建与路径**：普通玩家用 `/palace new <路径>` 在 `players/<自己的 UUID>/` 下新建笔记，作者是自己。领书、查位置和分享命令查找单篇笔记时，先查个人区，找不到再按整个笔记库的路径查找。本机房主仍在输入的位置新建，不写作者；其他管理员也在输入的位置新建，作者是自己。
- **谁能读、谁能改**：默认私有，作者和被分享的人能读；作者及获准编辑的人能改。可编辑也意味着可读。没有作者的笔记（以前的笔记、房主新建的笔记、收件箱）归本机房主；局域网里被授予管理权限的人也读不到。专用服务器上没有房主，这些笔记归管理员。`/palace give` 只给自己能读的笔记书，管理员可领任意笔记的书，但拿到书不等于有阅读权限。
- **分享**：`/palace share <玩家|everyone> read|edit <笔记>`，只有作者能操作（无作者的笔记由管理员处理）。`read` 分享阅读权限，`edit` 分享编辑权限；加密笔记和收件箱不能分享。笔记路径放在最后，可以含空格和中文。
- **取消分享**：`/palace unshare <玩家|everyone> <笔记>`，同样只有作者能操作。`/palace unshare everyone <笔记>` 可将对全世界公开的笔记改为私有。没有拒绝名单：只移除某个玩家时，如果笔记仍对所有人公开，他仍能读。
- 单篇笔记可在开头的 front matter 里写 `palace-owner`（作者 UUID）、`palace-read`（阅读名单）、`palace-edit`（编辑名单）；名单可填 `everyone` 或逗号分隔的玩家 UUID。分享命令会更新这些名单。
- **加密笔记只有作者能打开，收件箱永远私有**。收件箱和加密功能目前只有本机房主能用，开放局域网后房主仍可使用；专用服务器暂不支持。
- 服务端每次都会检查阅读权限。只要世界开放到局域网或是专用服务器（不论多人开关），不公开的笔记书名只显示"【私密笔记】#7f3a"这类占位文字。书名是写在书上的，谁拿到书都能看到：**纯单人时领的书仍是真实标题**，开放局域网前请把放着私密笔记的书收好；旧书要在被使用、放上书架或讲台被右键时才会改成新书名。
- 图片跟着所在文件夹走：图片所在的文件夹及其上层文件夹里只要有你读不了的笔记，你就看不到这张图。**私密笔记请放在子文件夹里**，否则根目录有一篇私密笔记，别人就看不到任何图片。
- 图片还必须和引用它的笔记在同一个区域：个人区 `players/<UUID>/` 里的笔记只能显示同一个个人区里的图片，个人区外的笔记也不能显示任何个人区里的图片。个人区里的图片只往上查到个人区为止，不受根目录等外面的笔记影响。
- 在外部（Obsidian 等）改了 `palace-read` / `palace-edit`，约 2 秒内生效；新放进笔记库的文件需要管理员 `/palace rescan`。
- 暂不支持多人实时同步编辑：两个人同时修改同一篇笔记，先保存的人写入，后保存的人会收到冲突提示。
- **没加密的笔记，服务器管理员可以直接在硬盘上看到**（局域网里就是房主）。只有加密能防住管理员。

快速收集按玩家所在地的本地日期归档；每天第一条及时区变化时，会标注时区（如 `(UTC+8)`）。自动备份以 UTC 时间命名，不受时区与夏令时影响。

## 关于加密

- 密码不会以任何形式保存；遗忘密码时只能使用恢复密钥重置。未设置恢复密钥时，遗忘密码将导致加密笔记永久无法打开。
- 恢复密钥等同于第二把钥匙，请妥善保管。
- 文件名、加密笔记中引用的图片不加密。
- 修改密码不会使旧备份失效：旧备份配合旧密码仍可解开当时的笔记。

## 从源码构建

```bash
./gradlew build
```

产物位于 `build/libs/`。开发时用 `./gradlew runClient` 启动测试客户端。需要 JDK 25。
