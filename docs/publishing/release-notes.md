Requires Minecraft Java Edition 26.3, Fabric Loader 0.20.1 or later, Fabric API, and Java 25.

**Improvements**
- Added interface translations for Traditional Chinese, Japanese, Korean, Russian, Spanish, French, German, and Brazilian Portuguese. These translations are machine-generated, and corrections are welcome.
- Item names, item descriptions, note book pages, error messages, and the Mod Menu description now follow the game language.
- Added English text to the offline tool and the server configuration comments.
- New worlds now include both `欢迎.md` and `Welcome.md`.
- The mod JAR now includes the MIT license and third-party notices.

**Notes**
- The server and clients must use the same version.
- The inbox folder (`收件箱`) and backup archive (`最新备份.zip`) keep their names for compatibility with existing data.
